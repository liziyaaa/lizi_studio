# LiZi Studio

李朝元的个人工作室。原生 HTML / CSS / JavaScript，无第三方运行依赖。

## 页面

- `index.html`：客户展示。定制服务、比赛服务、保研辅导、简历辅导，实践介绍、服务详情、合作流程、咨询摘要。
- `admin.html`：本机加密订单与收支台账。公开页面代码不包含账本数据，也不提供服务器登录。

## 使用工作台

1. 通过 HTTPS 打开 `admin.html`，首次创建本机账本并设置至少 10 位密码。
2. 新建订单，填写业务、客户代称、报价、交付日期与备注。
3. 在「流水」中逐笔添加收款、退款和成本。
4. 经常点击「导出备份」。下载的是 AES-GCM 加密 JSON，恢复时需要原密码。
5. 换设备：在新设备点「从加密备份恢复」，选择文件并输入备份密码。恢复为覆盖，不是合并。

### 数据和安全边界

- 账本只保存在当前浏览器的 localStorage；不上传 GitHub、不存服务器、不自动跨设备同步。
- PBKDF2-SHA256（310,000 次）派生 AES-256-GCM 密钥，每次保存使用随机 IV，密钥仅在解锁时保存在页面内存中。10 分钟无操作自动锁定。
- 页面 URL 本身公开，密码保护本机的账本内容，不是服务器身份认证。访问者在自己的设备上只能创建自己的空账本。
- 密码丢失不可恢复；清理浏览器数据、使用无痕窗口、换浏览器或换网站地址可能导致账本不可用。必须保留加密备份和密码。
- 解锁时仍须使用可信设备和浏览器。不能防止恶意扩展、设备木马或被篡改的网站代码。
- CSV 为未加密的全部订单汇总，不是可恢复备份，不包含逐笔流水。不要上传到公开仓库。
- 页面禁止外部网络请求和表单提交，没有第三方脚本或跟踪器。咨询表单只生成文本，客户须自行发送。
- 不保存身份证、银行卡密码或敏感简历附件，客户用代称记录即可。

## 统计口径

金额用整数分保存，显示人民币。

- 实收：所选月份发生的收款减退款。
- 成本：所选月份发生的成本支出。
- 现金净收益：实收减成本，未扣税费及个人工时，不等同于会计利润。
- 待收：所选月份创建的非取消订单，按报价减累计实收计算，下限为 0。
- 订单列表：月份按订单创建日期筛选；搜索与状态仅筛选列表。
- 趋势：截至所选月的六个月实收，退款可能使某月实收为负。
- 取消订单的真实收支保留统计，不能通过取消订单抹掉已发生收支。
- 已有流水的订单保留记录；误录流水可确认删除，退款请另记退款。

## 内容维护

服务详情在 `public.js`；展示内容在 `index.html`；视觉样式在 `styles.css`。

当前联系方式只采用用户已提供的 CSDN 主页；没有虚构微信、二维码、成交量、客户评价、奖项或报价。收费按需求确认。
